# Security policy

## Supported versions

Security fixes are made for the latest released version.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub security advisories: open the **Security** tab of this repository and choose
**Report a vulnerability**.

Please include:

- the plugin version, WordPress version and PHP version,
- a description of the problem and its impact,
- steps or a proof of concept to reproduce it.

We aim to acknowledge a report within 5 working days and to tell you what we plan to do. Please give us a
reasonable time to release a fix before you disclose the problem publicly. Reporters are credited in the changelog
unless they ask not to be.

## Scope

This policy covers the code in this repository. Problems in the oha.deals service itself should be sent to the
contact given on https://oha.deals.
