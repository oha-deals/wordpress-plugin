# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Please read it; it applies to all project spaces, including issues, pull requests and discussions.

In short: be respectful, accept constructive feedback, and do not harass or demean others.

## Reporting

To report unacceptable behaviour, use GitHub's private reporting on this repository (Security tab, "Report a
vulnerability" form) and mark the report as a conduct issue, or contact the maintainers at the address listed on
https://oha.deals. Reports are handled in confidence.

Maintainers may remove comments, close issues or pull requests, or block accounts that break these rules.
